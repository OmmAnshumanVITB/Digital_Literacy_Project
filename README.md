## Project Overview
This repository contains my **Digital Literacy Portfolio**, developed as part of my role as a **Student Digital Ambassador**. The goal of this project is to demonstrate proficiency in navigating the digital world, from professional branding to online safety. It covers five key modules of the Digital Literacy course at VIT Bhopal University.

## Module Summaries

### Module 1: Digital Awareness
* **Objective:** To act as a Student Digital Ambassador and create a visual resource that helps peers understand the importance of digital literacy.
* **Work Done:** Designed a one-page infographic using Canva that covers the definition of digital literacy, essential digital tools for B.Tech students, and safe internet practices.
* **Key Learning:** Learned to use visual hierarchy and icons to communicate technical concepts to a general audience.

### Module 2: Building a Digital Portfolio
* **Objective:** To establish a professional foundational presence on key platforms expected by employers and the academic community.
* **Work Done:** Created and optimized professional profiles on GitHub, LinkedIn, and Kaggle. This included setting up a special GitHub profile README with my branch and learning goals.
* **Key Learning:** Understood how to maintain a minimal yet professional online identity without sharing sensitive personal details.

### Module 3: Coding and Collaboration Platforms
* **Objective:** To build familiarity with platforms used for coding practice and cloud-based team collaboration.
* **Work Done:** Completed a beginner Python challenge on HackerRank and developed a 5-question "Digital Literacy Awareness Quiz" using Google Forms.
* **Form Link:** [Digital Literacy Quick Assessment Quiz](https://forms.gle/jkSsEWetzEKScYBW6)
* **Key Learning:** Practiced linking data between Google Forms and Sheets to track real-time responses and progress.

### Module 4: Digital Communication and Etiquette
* **Objective:** To master professional communication rules for academic and corporate environments.
* **Work Done:** Drafted two professional emails—one for a deadline extension and one for an Amazon internship inquiry—and created a "Social Media Do’s and Don’ts" checklist.
* **Key Learning:** Recognized that effective digital communication relies on proper structure, tone, and clear subject lines. 

### Module 5: Cybercrime Awareness and Prevention
* **Objective:** To research realistic online threats and produce awareness resources for the student community.
* **Work Done:** Authored a case study on Cyberbullying and compiled a "Stay Safe Online" checklist featuring 8 actionable tips, including specific UPI safety measures.
* **Key Learning:** Identified the official Indian reporting channels, such as the 1930 Helpline and the National Cyber Crime Portal.
